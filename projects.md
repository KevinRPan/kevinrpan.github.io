## Current

### askdata.app &mdash; natural language for structured data

[**askdata.app**](https://askdata.app) is an LLM-powered interface that lets users explore datasets by asking questions in plain English. You connect a dataset, ask a question, and get back an answer, a chart, and the query that produced it -- so you can check the work.

The interesting hard parts are schema understanding, hallucination control, and evaluation. Status: working prototype. [Read the build notes &rarr;](/askdata)

## Selected past work

### Bernoulli One &mdash; continuous patient monitoring
Built a custom physiological indicator that detected severe events **12 seconds earlier than the industry standard** at equal accuracy -- enough lead time to change clinical action. Time-series and data mining on continuous patient monitoring data. [Details](/consulting).

### BUILD &mdash; North Star for a national nonprofit
Helped a national youth-serving nonprofit shift their North Star from program count to student outcomes, then built the automated reporting connecting it to their data sources. [Write-up](https://blog.deltanalytics.org/asking-the-right-data-questions-a14cb37dc177).

### Machine Learning for Good &mdash; open-source ML curriculum
Contributed to [Delta Analytics'](http://www.deltanalytics.org/) open-source ML course for nonprofit data practitioners. [GitHub](https://github.com/DeltaAnalytics/machine_learning_for_good).

### Handy &mdash; R package for data cleaning
An [R package](/2018-02-26-handy-package/) for common data cleaning and exploration tasks -- name cleaning, variable summaries, human-readable plot scales, Excel output.
