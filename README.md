# kevinrpan.com

Personal site of Kevin Pan, hosted on GitHub Pages at [kevinrpan.com](https://kevinrpan.com).

Built with Jekyll on the [Beautiful Jekyll](https://github.com/daattali/beautiful-jekyll) theme (v6.0.1).

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.

## Structure

- `index.md` -- About page (homepage)
- `_posts/` -- blog posts, listed at `/blog`
- `_drafts/` -- unpublished drafts and the content calendar (never built)
- `projects.md`, `consulting.md`, `askdata.md` -- standalone pages
- `_config.yml` -- site settings (navbar, colors, social links, analytics)
